====================================================
 Kiro Auto Allow  v1.0.0
 Kiro の「Allow」を自動でクリックするツール
====================================================

■ これは何？

Kiro を使っていると、コマンド実行前に確認画面が出ます。

    Your approval is required to continue: ...
    [Allow] [Always allow] [Deny] [Always deny]

このツールを起動しておくと、一番左の「Allow」だけを
自動でクリックしてくれます。毎回手で押す必要がなくなります。

「Always allow」「Deny」「Always deny」「Cancel」は
絶対にクリックしません。


■ 使い方（3ステップ）

  1. KiroAutoAllow.exe をダブルクリック
  2. 「Auto Allow: OFF」のボタンを押して「ON」にする
  3. あとは普通に Kiro を使うだけ

  OFF のときは何もしません。
  Python などのインストールは不要です。


■ 初回起動時に警告が出たら

  「WindowsによってPCが保護されました」と表示されることがあります。
  署名を付けていないだけで、動作に問題はありません。

    ［詳細情報］ をクリック → ［実行］ をクリック

  で起動できます。


■ 完了通知

  Kiro の処理が終わって、次のプロンプトを送れる状態になったら
  知らせてくれます。

    ・このアプリのウィンドウが最前面に出てくる
    ・音が鳴る
    ・タスクバーのアイコンが点滅する
    ・画面に緑の帯で「処理が完了しました」と出る（クリックで消えます）

  最前面に出るのは通知のときだけです。常に最前面に固定はしません。
  5秒後に自動で元に戻り、緑の帯をクリックすればすぐ解除できます。

  前面に出るだけでキー入力は奪いません。他のアプリで文字を
  入力している途中でも、その入力が取られることはありません。

  「完了通知: ON / OFF」で切り替えられます。
  自動クリックを使わず、通知だけ使うこともできます。


■ 作業中の画面が切り替わらないか？

  切り替わりません。

  クリックはマウスを動かさない方式（UI Automation）で行います。
  それでも Kiro が前面に出てきた場合は、クリック前に使っていた
  ウィンドウへ自動でフォーカスを戻します。


■ 止めたいとき

  ・画面の［緊急停止］ボタンを押す
  ・または Esc キーを素早く2回押す
  ・または「Auto Allow: ON」を押して OFF にする

  Esc は他のアプリの操作を邪魔しません。


■ 画面の見方

  Auto Allow: ON / OFF … 監視のスイッチ
  現在の状態            … 停止中 / 監視中
  Kiro                  … Kiro を見つけられているか
  Allow クリック回数    … 実際に押した回数
  ログ欄                … 何が起きたかの記録

  ［今すぐ1回だけ実行］
      いま出ている承認画面を1回だけ処理します。動作確認に便利です。

  ［UI要素を確認］
      うまく動かないときの調査用。Kiro から読み取れた
      ボタン情報をテキストに書き出します。


■ 誤クリックしない仕組み

  次の条件を全部満たしたときだけクリックします。

    ・ウィンドウの持ち主が kiro.exe であること
    ・ボタンの種類が Button であること
    ・ボタン名が「Allow」と完全一致すること
      （Always allow や allow は一致しないので押しません）
    ・同じ承認ブロックに Always allow と Deny があること
    ・その Allow が同じ行の一番左にあること
    ・ボタンが有効で画面内にあり、Kiro のウィンドウの内側にあること

  クリックする直前にもう一度すべて確認し、
  条件が崩れていれば中止してログに残します。

  Kiro 以外のアプリやブラウザに出ている「Allow」は
  対象になりません。

  画面の座標を決め打ちしていないので、画面の解像度や
  ウィンドウの大きさ・位置が変わっても動きます。

  1分間に12回を超えてクリックした場合は、異常とみなして
  自動的に停止します。


■ 保存されるファイル

  C:\Users\(ユーザー名)\AppData\Local\KiroAutoAllow\

    config.json   設定ファイル（初回起動時に自動作成）
    logs\         日付ごとのログ
    ui_dumps\     UI要素の書き出し

  アンインストールは、exe とこのフォルダを削除するだけです。
  レジストリは触りません。


■ 動作環境

  Windows 11（64bit）
  Kiro がインストールされていること


■ うまく動かないとき

  ・「Kiro のウィンドウが見つかりません」
      → Kiro を起動し、最小化を解除してください

  ・何も反応しない
      → 「Auto Allow」が ON になっているか確認してください

  ・「Invoke は実行できましたが承認 UI が残っています」
      → Kiro のウィンドウを手前に出しておいてください

  詳しい情報は README.md を参照してください。
